Process Overview: The algorithm starts with class mean representatives and iteratively optimizes them using contrastive loss to achieve better class separation in the embedding space.
🧮 Contrastive Loss Mechanism
graph LR subgraph "For Each Class Representative r_c" A[🎯 Representative r_c] --> B[📊 Find Positive Samples
Same Class P^c] A --> C[📊 Find Negative Samples
Different Classes N^c] B --> D[📐 Compute cos(r_c, P^c)] C --> E[📐 Compute cos(r_c, N^c)] D --> F[⬅️ Pull Term
-mean(cos(r_c, P^c))] E --> G[➡️ Push Term
λ × mean(max(0, cos(r_c, N^c) - margin))] F --> H[📊 Total Loss
L = Pull + Push] G --> H end style A fill:#ffeb3b style B fill:#4caf50 style C fill:#f44336 style F fill:#4caf50 style G fill:#f44336 style H fill:#ff9800
Contrastive Loss Formula:
L = Σ_c [ -mean(cos(r_c, P^c)) + λ × mean(max(0, cos(r_c, N^c) - margin)) ]
Loss Components:
  • Pull Term (Green): Minimizes distance to positive samples (same class)
  • Push Term (Red): Maximizes distance from negative samples (different classes)
  • Margin: Minimum required distance from negatives
  • λ (Lambda): Balances pull vs push strength
