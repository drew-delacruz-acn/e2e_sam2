SAM2 Video Segmentation Data Structures

This document visualizes the data structures and formats used in the SAM2 Video Segmentation Pipeline.

Input Data Formats

The pipeline starts with detection data in JSON format and video frames as images.

classDiagram class DetectionJSON { Array of Detections } class Detection { +String label +Float confidence +Array[4] coordinates [x1,y1,x2,y2] } class VideoFrames { +Image frame_0000.jpg +Image frame_0001.jpg +... } DetectionJSON *-- Detection : contains

Example Detection JSON (0.json):

[
  {
    "label": "Time Stick",
    "confidence": 0.95,
    "coordinates": [100, 150, 200, 250]
  },
  {
    "label": "Person",
    "confidence": 0.92,
    "coordinates": [300, 400, 450, 650]
  }
]

Transformation: JSON to Tracking Format

The pipeline converts per-frame detection data into an object-centric tracking format.

flowchart TD A[Frame 0 Detections] --> D[Object-Centric Format] B[Frame 1 Detections] --> D C[Frame N Detections] --> D D --> E["Tracking Objects (List of Objects with Appearances Across Frames)"] subgraph "Tracking Object" F[Object ID] G[Object Name] H[Frame Occurrences] end E --> F E --> G E --> H H --> I["Frame Number"] H --> J["Bounding Box"] H --> K["Confidence"]

Tracking Objects Structure:

[
  {
    "objectID": 1,
    "objectName": "Time Stick",
    "frameOccurences": [
      {
        "frameNum": 0,
        "box": [100, 150, 200, 250],
        "confidence": 0.95
      },
      {
        "frameNum": 1,
        "box": [102, 153, 202, 253],
        "confidence": 0.94
      }
    ]
  },
  {
    "objectID": 2,
    "objectName": "Person",
    "frameOccurences": [
      {
        "frameNum": 0,
        "box": [300, 400, 450, 650],
        "confidence": 0.92
      }
    ]
  }
]

SAM2 Segmentation Result Structure

After segmentation, the pipeline produces a dictionary mapping frame indices to object segmentation masks.

classDiagram class VideoSegments { +Dict frame_to_segments } class FrameSegments { +Dict object_id_to_mask } class Mask { +Array[H,W] binary_mask } VideoSegments *-- FrameSegments : contains FrameSegments *-- Mask : contains

Video Segments Structure:

{
  0: {                          # Frame index
    "1": numpy.array([H,W]),    # Object ID -> Binary mask
    "2": numpy.array([H,W])
  },
  1: {
    "1": numpy.array([H,W]),
    "2": numpy.array([H,W])
  }
}

Output JSON Format

The final output is an object-centric representation of tracking and detection data.

classDiagram class SegmentationResults { +Array of ObjectSummary } class ObjectSummary { +Int samObjectId +Array samDictatedAppearances +Array cdfsodPredictions } class SAMAppearance { +Int frameNum +Array[4] boundingBox } class CDFSODPrediction { +Int frameNumber +String class +Float confidence } SegmentationResults *-- ObjectSummary : contains ObjectSummary *-- SAMAppearance : contains ObjectSummary *-- CDFSODPrediction : contains

Final Result JSON Structure:

[
  {
    "samObjectId": 1,
    "samDictatedAppearances": [
      {"frameNum": 0, "boundingBox": [100, 150, 200, 250]},
      {"frameNum": 1, "boundingBox": [102, 153, 202, 253]}
    ],
    "cdfsodPredictions": [
      {"frameNumber": 0, "class": "Time Stick", "confidence": 0.95},
      {"frameNumber": 1, "class": "Time Stick", "confidence": 0.94}
    ]
  },
  {
    "samObjectId": 2,
    "samDictatedAppearances": [
      {"frameNum": 0, "boundingBox": [300, 400, 450, 650]}
    ],
    "cdfsodPredictions": [
      {"frameNumber": 0, "class": "Person", "confidence": 0.92}
    ]
  }
]
