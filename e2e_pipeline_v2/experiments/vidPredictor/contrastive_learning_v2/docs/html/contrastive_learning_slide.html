Contrastive Loss:
L = Σ_c [ -mean(cos(r_c, P^c)) + λ × mean(max(0, cos(r_c, N^c) - margin)) ]

🎯 Key Concepts:

  • Pull Term: Attracts representatives closer to same-class samples
  • Push Term: Repels representatives from different-class samples
  • Margin: Minimum required cosine distance from negatives
  • Lambda (λ): Controls balance between pull and push forces
